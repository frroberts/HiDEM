# Ice block

This is the most simple setup, it generates one block of ice and drops it into water, it will bop up and down, and since the sheet is slightly asymmetric it will eventually break. There are no speed limits etc. and it is unlikely the simulation behaves physically correct this is merely an example of how to set up the code.

The config file is mostly as simple as it gets, as is the main file.

## Building

Build according to XXX. Use `IceBlock` as the `Type` for `-DHiDEMType=<Type>`
